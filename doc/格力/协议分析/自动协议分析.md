# 格力空调红外协议分析文档

## 1. 协议概述

本文档由自动分析工具根据 `32` 条 Learn 报文生成，用于整理 `格力` 空调红外报文的脉冲编码规则、数据段结构以及字段观察结论。

### 1.1 脉冲编码规则

| 逻辑值 | 脉冲编码（学习码） | 观察说明 |
|---|---|---|
| `1` | `xx FD xx FA` | bit 1 通常由同类 Mark + 较长 Space 组成 |
| `0` | `xx FD xx FE` | bit 0 通常由同类 Mark + 较短 Space 组成 |

- 解码输入模式：`manifest`
- 可解码有效帧数：`64` 帧
- 每条指令帧数：2 帧
- 每帧有效载荷：8 字节 / 64 bit
- 当前解码假设位序：`LSB-first`

### 1.2 报文结构

| 组成部分 | 内容 |
|---|---|
| 前导码/Header | 当前观察到的 Header 样本：`8DE309F2`, `8FE30AF2`, `8FE30DF2`, `91E3FAF1`, `92E3FBF1`, `93E30DF2` 等 43 种 |
| 数据段 | 每条指令 2 帧，单帧 payload 长度为 8 字节 / 64 bit |
| 帧间分隔/结束标记 | `9B82`, `A182`, `A782`, `AA82`, `AC82`, `AD82` 等 22 种 |
| 补位/尾段 | 解析前会去掉 `0100` 终止符和尾部 `FF` 填充；尾部额外 bit 约为 4 bit |
